# Student Management System

A console-based Java application for managing student records using Core Java, JDBC, and MySQL.

## Features
- Add Student
- View Students
- Search Student
- Update Student
- Delete Student
- Input Validation
- Exception Handling

## Tech Stack
- Core Java
- JDBC
- MySQL
- Collections Framework
- OOPs

## Database
MySQL database with normalized schema design and indexed queries.

## Concepts Used
- OOPs
- JDBC Connectivity
- Exception Handling
- Collections Framework
- CRUD Operations
- SQL Queries

## How to Run
1. Create MySQL database using schema.sql
2. Update DB credentials in DBConnection.java
3. Compile and run Main.java
